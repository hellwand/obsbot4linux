# Field ledger: Tiny 2 Lite

Revision 2 (2026-11-12), for revision 2 of the 1.0 design spec
(`docs/superpowers/specs/2026-11-01-obsbot4linux-1.0-design.md`). One row per leaf of spec §4.3
and per action of spec §4.4. The rules for this file are in spec §8.5; the model notes are in
spec §8.8. Nothing here was sent to a camera to write it.

**Wire notation.** `short XX LL <v>`: short command on extension-unit selector 6 (command, length,
value). `framed 0xNNNN`: framed command on selector 2 (written), to receiver 4 unless `rcv` names
another; payloads are little-endian. `query 0xNNNN`: framed query on selector 2 and its answer,
read from selector 2. `status 0xNN`: byte at that offset of the status block (selector 6 read).
`selector 0x0c` and `selector 0x0d`: the preset list and its entries. `0x0104 byte N`: byte N
of the answer to query `0x0104`. `UVC CT` / `UVC PU`: standard UVC camera-terminal and
processing-unit controls, through V4L2. On the wire, pitch is positive down and yaw positive to
the camera's left; the model converts to the units of spec §4.2. Preset layout: 24 bytes,
`u32 lead, f32 yaw, f32 pitch, f32 0, f32 zoom, f32 last` (`last` −1000 for presets and views,
0 for start pose and returns).

**Evidence** (the levels defined in the spec's preamble). `capture N`: recorded from the vendor
app in capture N. `measured <date>`: measured on the camera on that date; `#N` names the public
issue or pull request that records it. `none`: no backing today. `daemon`: not a camera value (spec §8.5).
Levels hold per field, value and bound (spec §8.5): where values or bounds of one row have
different evidence, the evidence column names each. Column §9.3: the row of spec §9.3 for the
field, value or bound that has no backing today.

**Asleep** (spec §5.7): `ignored`, `accepted` or `unknown`; `–` for read-only leaves. "Not read
asleep": the readback is not sent while the camera sleeps, so a write stays pending until wake.
**`readback:false`** shows as `none` in the readback column. **`settle_ms`** is 3000 for every
writable leaf with a readback: one model-wide bound from the worst measured case (zone tracking
follows 1–3 s after the write, #81; the target-lock status about 1 s). Per-leaf values are CAM-5.
